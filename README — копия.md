# Слово — тренажёр русского языка

Интерактивный учебник и тренажёр по русскому языку для 7–8 классов. Проект превращает школьные правила в короткие учебные блоки: объяснение, новый пример, подсказка, практика и итоговый тест с оценкой.

## Что уже есть в прототипе

- современный адаптивный интерфейс для компьютера и телефона;
- маршрут по темам курса;
- демонстрационная тема «Фонетика и графика»;
- правило из предоставленного пользователем учебника;
- новые примеры и учебные формулировки;
- пошаговое объяснение;
- подсказки при выполнении заданий;
- тест из трёх вопросов с результатом и оценкой;
- подготовленная fullstack-основа для авторизации, базы данных и сохранения прогресса.

## Технологии

- React 19 + TypeScript;
- Vite;
- Tailwind CSS 4;
- shadcn/ui;
- Wouter;
- Express + tRPC;
- Drizzle ORM + MySQL/TiDB;
- Vitest.

## Локальный запуск

Требования: Node.js 20+ и pnpm 10+.

```bash
git clone https://github.com/<ваш-аккаунт>/russian-language-trainer.git
cd russian-language-trainer
pnpm install --frozen-lockfile
pnpm dev
```

После запуска откройте адрес, который покажет Vite. Для проверки проекта:

```bash
pnpm check
pnpm build
pnpm test
```

## Переменные окружения

Скопируйте пример настроек:

```bash
cp config.example .env
```

В Windows PowerShell:

```powershell
Copy-Item config.example .env
```

Секреты в `.env` нельзя добавлять в GitHub. Файл `.env` уже исключён через `.gitignore`.

## Работа с учебным контентом

Текущая версия содержит демонстрационный первый урок. Следующий этап — перенести содержание учебника по темам и создать оригинальные примеры, задания и тесты.

Формулировки правил из предоставленного источника можно использовать в закрытом прототипе при наличии законных оснований. Перед публичной публикацией необходимо проверить права на воспроизведение текста учебника. Примеры, иллюстрации и задания должны быть новыми либо иметь разрешённую лицензию.

Подробные ограничения описаны в [CONTENT_RIGHTS.md](CONTENT_RIGHTS.md).

## GitHub Actions

Workflow в `.github/workflows/ci.yml` автоматически запускает при каждом Pull Request и push в `main`:

- установку зависимостей по lock-файлу;
- проверку TypeScript;
- production-сборку;
- Vitest.

## Архитектура следующего этапа

Для сохранения прогресса следует добавить таблицы:

- `lessons` — темы и учебные блоки;
- `questions` — задания и варианты ответов;
- `attempts` — попытки прохождения;
- `progress` — прогресс ученика;
- `mistakes` — ошибки для повторения.

Затем подключить защищённые tRPC-процедуры и личный кабинет ученика.
