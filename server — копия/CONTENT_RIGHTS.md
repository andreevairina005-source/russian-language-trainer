# Учебное содержание и авторские права

Проект создаётся на основе учебного материала, который был предоставлен владельцем задачи.

## Правила для команды проекта

1. Не публиковать полный скан, PDF, DjVu или распознанную копию учебника в репозитории.
2. Не переносить без проверки прав большие фрагменты текста, иллюстрации и авторские задания.
3. Формулировки правил использовать в точном виде только при наличии законных оснований и с учётом территории распространения продукта.
4. Примеры, упражнения, варианты тестов и объяснения к ним создавать заново.
5. Источник и сведения о правах хранить в закрытых материалах проекта, если публикация источника не разрешена.
6. Для публичного релиза провести правовую проверку: срок охраны, правообладатель, договор или разрешение на воспроизведение.
7. Не добавлять в GitHub персональные данные учеников, реальные токены, ключи, пароли и содержимое закрытых учебных групп.

## Текущий статус

В прототипе используется короткая учебная формулировка правила, полученная из предоставленного источника, а примеры и тестовые задания созданы для этого приложения отдельно. Перед публичной публикацией необходимо подтвердить право на такое использование или заменить правило на оригинальное объяснение своими словами.
